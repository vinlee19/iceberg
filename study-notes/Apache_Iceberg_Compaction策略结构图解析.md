# Apache Iceberg Compaction 策略结构图解析

## 摘要

本文档通过详细的结构图和架构示意图，深入展示 Apache Iceberg 三种主要 compaction 策略（BIN-PACK、SORT、Z-ORDER）的内部执行机制、数据流转路径、内存分配模式和性能特征差异，为数据工程师提供直观的技术理解。

1. [BIN-PACK 策略结构解析](#1-bin-pack-策略结构解析)
2. [SORT 策略架构详解](#2-sort-策略架构详解)
3. [Z-ORDER 策略内部机制](#3-z-order-策略内部机制)
4. [文件分组与分布机制](#4-文件分组与分布机制)
5. [内存资源分配对比](#5-内存资源分配对比)
