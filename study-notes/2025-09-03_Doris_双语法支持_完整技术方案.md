# Apache Doris 双语法支持完整技术方案
## ALTER TABLE EXECUTE + CALL 语法兼容实现

## 1. 方案概述

### 1.1 目标
在Apache Doris中同时支持两种Procedure调用语法：
1. **ALTER TABLE语法**: `ALTER TABLE table_name EXECUTE procedure_name(args...)`
2. **CALL语法**: `CALL procedure_name(args...)` (标准SQL语法)

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        SQL Parser Layer                         │
│  ┌─────────────────────┐    ┌─────────────────────────────────┐ │
│  │   ALTER TABLE       │    │         CALL                    │ │
│  │   EXECUTE           │    │    procedure_name(args...)     │ │
│  │   #alterTableExecute│    │    #callProcedure               │ │
│  └─────────────────────┘    └─────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                    │                          │
                    ▼                          ▼
┌─────────────────────────────────────────────────────────────────┐
│                 LogicalPlanBuilder                              │
│  ┌─────────────────────┐    ┌─────────────────────────────────┐ │
│  │visitAlterTableExecute│    │    visitCallProcedure           │ │
│  │                     │    │                                 │ │
│  │ AlterTableExecute   │    │    CallCommand                  │ │
│  │ Command             │    │    (enhanced)                   │ │
│  └─────────────────────┘    └─────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘

                    ▼                          ▼

│  │                                                             │ │
│  │  ┌─────────────┐ ┌─────────────┐ ┌─────────────────────┐   │ │
│  │  │  Iceberg    │ │   Paimon    │ │    Future           │   │ │
│  │  │ Procedures  │ │ Procedures  │ │   DataSources       │   │ │
│  │  └─────────────┘ └─────────────┘ └─────────────────────┘   │ │
│  └─────────────────────────────────────────────────────────────┘ │
```

## 2. 语法支持实现

### 2.1 现有CALL语法分析

Doris已经支持`CALL`语法，定义在`DorisParser.g4`中：
```antlr
// 第42行已存在
| CALL name=multipartIdentifier LEFT_PAREN (expression (COMMA expression)*)? RIGHT_PAREN #callProcedure
```

对应的处理流程：
1. `LogicalPlanBuilder.visitCallProcedure()` - 解析为`CallCommand`
2. `CallCommand.run()` - 调用`CallFunc.getFunc()`
3. `CallFunc.getFunc()` - 根据函数名分发到具体实现

### 2.2 增强CALL语法支持

#### 2.2.1 修改CallFunc分发逻辑

**位置**: `fe/fe-core/src/main/java/org/apache/doris/nereids/trees/plans/commands/call/CallFunc.java`

```java
package org.apache.doris.nereids.trees.plans.commands.call;

import org.apache.doris.analysis.UserIdentity;
import org.apache.doris.nereids.analyzer.UnboundFunction;
import org.apache.doris.qe.ConnectContext;

/**
 * Enhanced CallFunc with TableProcedure support
 */
public abstract class CallFunc {

    /**
     * Get the instance of CallFunc with enhanced TableProcedure support
     */
    public static CallFunc getFunc(ConnectContext ctx, UserIdentity user, UnboundFunction unboundFunction,
            String originSql) {
        String funcName = unboundFunction.getName().toUpperCase();
        
        switch (funcName) {
            // 内置函数优先处理
            case "EXECUTE_STMT":
                return CallExecuteStmtFunc.create(user, unboundFunction.getArguments());
            case "FLUSH_AUDIT_LOG":
                return CallFlushAuditLogFunc.create(user, unboundFunction.getArguments());
                
            // TableProcedure处理 - 新增逻辑
            default:
                // 首先尝试作为TableProcedure处理
                CallFunc tableProcedureFunc = tryCreateTableProcedureFunc(ctx, user, unboundFunction);
                if (tableProcedureFunc != null) {
                    return tableProcedureFunc;
                }
                
                // 回退到原有的PlSQL处理
                return CallProcedure.create(ctx, originSql);
        }
    }
    
    /**
     * 尝试创建TableProcedure函数调用
     */
    private static CallFunc tryCreateTableProcedureFunc(ConnectContext ctx, UserIdentity user, 
                                                       UnboundFunction unboundFunction) {
        String procedureName = unboundFunction.getName();
        
        // 检查当前Catalog是否支持该Procedure
        CatalogIf currentCatalog = ctx.getCurrentCatalog();
        if (currentCatalog != null) {
            TableProcedure procedure = currentCatalog.getProcedure(procedureName);
            if (procedure != null) {
                // 创建TableProcedure调用
                return CallTableProcedureFunc.create(ctx, user, unboundFunction, procedure);
            }
        }
        
        return null;
    }

    public abstract void run() throws Exception;
}
```

#### 2.2.2 新增CallTableProcedureFunc

**位置**: `fe/fe-core/src/main/java/org/apache/doris/nereids/trees/plans/commands/call/CallTableProcedureFunc.java`

```java
package org.apache.doris.nereids.trees.plans.commands.call;

import org.apache.doris.analysis.UserIdentity;
import org.apache.doris.catalog.Env;
import org.apache.doris.common.AnalysisException;
import org.apache.doris.datasource.CatalogIf;
import org.apache.doris.nereids.analyzer.UnboundFunction;
import org.apache.doris.nereids.trees.expressions.Expression;
import org.apache.doris.nereids.trees.plans.commands.info.TableProcedure;
import org.apache.doris.qe.ConnectContext;

import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;

import java.util.Arrays;
import java.util.List;
import java.util.Objects;

/**
 * CallTableProcedureFunc - CALL语法的TableProcedure实现
 * 处理类似 CALL expire_snapshots('2024-01-01', 5) 这样的调用
 */
public class CallTableProcedureFunc extends CallFunc {
    private static final Logger LOG = LogManager.getLogger(CallTableProcedureFunc.class);
    
    private final ConnectContext ctx;
    private final UserIdentity user;
    private final UnboundFunction unboundFunction;
    private final TableProcedure procedure;

    private CallTableProcedureFunc(ConnectContext ctx, UserIdentity user, 
                                  UnboundFunction unboundFunction, TableProcedure procedure) {
        this.ctx = Objects.requireNonNull(ctx, "ConnectContext cannot be null");
        this.user = Objects.requireNonNull(user, "UserIdentity cannot be null");
        this.unboundFunction = Objects.requireNonNull(unboundFunction, "UnboundFunction cannot be null");
        this.procedure = Objects.requireNonNull(procedure, "TableProcedure cannot be null");
    }

    public static CallFunc create(ConnectContext ctx, UserIdentity user, 
                                 UnboundFunction unboundFunction, TableProcedure procedure) {
        return new CallTableProcedureFunc(ctx, user, unboundFunction, procedure);
    }

    @Override
    public void run() throws Exception {
        String procedureName = unboundFunction.getName();
        List<Expression> arguments = unboundFunction.getArguments();
        
        LOG.info("Executing TableProcedure via CALL syntax: {} with {} arguments", 
                procedureName, arguments.size());

        try {
            // 权限检查
            // TODO: 添加对TableProcedure的权限检查
            // checkPrivileges(ctx, user, procedureName);
            
            // 参数验证和转换
            Object[] convertedArgs = validateAndConvertArguments(arguments);
            
            // 生成虚拟表名用于Procedure执行
            // CALL语法中没有显式表名，使用当前catalog的默认配置
            List<String> virtualTableName = generateVirtualTableName();
            
            // 执行TableProcedure
            procedure.execute(ctx, virtualTableName, convertedArgs);
            
            LOG.info("Successfully executed TableProcedure {} via CALL syntax", procedureName);
            
        } catch (Exception e) {
            LOG.error("Failed to execute TableProcedure {} via CALL syntax: {}", 
                     procedureName, e.getMessage(), e);
            throw e;
        }
    }

    /**
     * 参数验证和转换
     */
    private Object[] validateAndConvertArguments(List<Expression> arguments) throws Exception {
        List<TableProcedure.ParameterInfo> expectedParams = procedure.getParameters();
        
        // 参数数量验证
        if (arguments.size() != expectedParams.size()) {
            throw new AnalysisException(String.format(
                    "Procedure '%s' expects %d arguments, but %d were provided. " +
                    "Expected signature: %s(%s)",
                    procedure.getName(), expectedParams.size(), arguments.size(),
                    procedure.getName(), formatParameterSignature(expectedParams)));
        }
        
        // 参数类型转换
        Object[] convertedArgs = new Object[arguments.size()];
        for (int i = 0; i < arguments.size(); i++) {
            Expression expr = arguments.get(i);
            TableProcedure.ParameterInfo paramInfo = expectedParams.get(i);
            
            // 转换Expression到具体的Java对象
            convertedArgs[i] = convertExpressionToValue(expr, paramInfo);
        }
        
        return convertedArgs;
    }

    /**
     * 生成虚拟表名用于CALL语法
     * 由于CALL语法没有指定具体表名，我们需要提供一个默认值或者让Procedure自己处理
     */
    private List<String> generateVirtualTableName() {
        // 对于CALL语法，一些Procedure可能不需要具体的表名
        // 比如一些全局操作的Procedure
        
        CatalogIf currentCatalog = ctx.getCurrentCatalog();
        String currentDb = ctx.getDatabase();
        
        // 返回当前catalog和database，表名为空
        // 具体的Procedure实现需要能够处理这种情况
        return Arrays.asList(currentCatalog.getName(), currentDb != null ? currentDb : "default", "");
    }

    /**
     * 表达式值转换 (复用AlterTableExecuteCommand的逻辑)
     */
    private Object convertExpressionToValue(Expression expr, TableProcedure.ParameterInfo paramInfo) 
            throws Exception {
        // TODO: 实现完整的Expression到Java对象的转换逻辑
        // 这里可以复用AlterTableExecuteCommand中的转换逻辑
        
        if (expr instanceof org.apache.doris.nereids.trees.expressions.literal.Literal) {
            org.apache.doris.nereids.trees.expressions.literal.Literal literal = 
                (org.apache.doris.nereids.trees.expressions.literal.Literal) expr;
            return convertLiteralValue(literal, paramInfo);
        } else {
            throw new AnalysisException("Complex expressions in procedure parameters are not yet supported");
        }
    }

    /**
     * 字面值转换
     */
    private Object convertLiteralValue(org.apache.doris.nereids.trees.expressions.literal.Literal literal,
                                     TableProcedure.ParameterInfo paramInfo) throws AnalysisException {
        Class<?> targetType = paramInfo.getType();
        Object value = literal.getValue();
        
        // 类型转换逻辑 (复用AlterTableExecuteCommand的逻辑)
        if (targetType == String.class) {
            return value != null ? value.toString() : null;
        } else if (targetType == Integer.class || targetType == int.class) {
            if (value instanceof Number) {
                return ((Number) value).intValue();
            } else {
                return Integer.valueOf(value.toString());
            }
        } else if (targetType == Long.class || targetType == long.class) {
            if (value instanceof Number) {
                return ((Number) value).longValue();
            } else {
                return Long.valueOf(value.toString());
            }
        } else if (targetType == Boolean.class || targetType == boolean.class) {
            if (value instanceof Boolean) {
                return value;
            } else {
                return Boolean.valueOf(value.toString());
            }
        }
        
        throw new AnalysisException(String.format("Unsupported parameter type: %s", targetType.getSimpleName()));
    }

    /**
     * 格式化参数签名用于错误信息
     */
    private String formatParameterSignature(List<TableProcedure.ParameterInfo> params) {
        return params.stream()
                .map(p -> p.getType().getSimpleName() + " " + p.getName())
                .collect(java.util.stream.Collectors.joining(", "));
    }
}
```

## 3. 具体Procedure实现增强

### 3.1 支持CALL语法的Iceberg Procedure示例

#### 3.1.1 ExpireSnapshots - 表级操作

```java
package org.apache.doris.datasource.iceberg.procedure;

import org.apache.doris.nereids.trees.plans.commands.info.TableProcedure;
import org.apache.doris.qe.ConnectContext;

import com.google.common.collect.ImmutableList;
import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;

import java.util.List;

/**
 * Enhanced IcebergExpireSnapshotsProcedure with CALL syntax support
 */
public class IcebergExpireSnapshotsProcedure extends TableProcedure {
    private static final Logger LOG = LogManager.getLogger(IcebergExpireSnapshotsProcedure.class);
    private static final IcebergExpireSnapshotsProcedure INSTANCE = new IcebergExpireSnapshotsProcedure();
    
    private IcebergExpireSnapshotsProcedure() {
        super("expire_snapshots", 
              "Remove old snapshots and their associated data and delete files",
              ImmutableList.of(
                  new ParameterInfo("table_name", String.class, "Table name (required for CALL syntax)"),
                  new ParameterInfo("older_than", String.class, "Remove snapshots older than this timestamp", true, null),
                  new ParameterInfo("retain_last", Integer.class, "Number of recent snapshots to keep", true, 1),
                  new ParameterInfo("max_concurrent_deletes", Integer.class, "Max concurrent delete operations", true, 1)
              ));
    }
    
    public static IcebergExpireSnapshotsProcedure getInstance() {
        return INSTANCE;
    }

    @Override
    public void execute(ConnectContext ctx, List<String> tableName, Object[] args) throws Exception {
        LOG.info("Executing expire_snapshots procedure");
        
        // 判断是CALL语法还是ALTER TABLE EXECUTE语法
        boolean isCallSyntax = isCallSyntaxInvocation(tableName, args);
        
        if (isCallSyntax) {
            executeViaCallSyntax(ctx, args);
        } else {
            executeViaAlterTableSyntax(ctx, tableName, args);
        }
    }

    /**
     * 判断是否为CALL语法调用
     */
    private boolean isCallSyntaxInvocation(List<String> tableName, Object[] args) {
        // CALL语法的特征：
        // 1. tableName最后一个元素为空字符串
        // 2. 第一个参数是table_name
        return tableName.size() >= 3 && 
               (tableName.get(tableName.size() - 1) == null || tableName.get(tableName.size() - 1).isEmpty()) &&
               args.length > 0 && args[0] instanceof String;
    }

    /**
     * 通过CALL语法执行
     * CALL expire_snapshots('iceberg_catalog.db.table', '2024-01-01', 5)
     */
    private void executeViaCallSyntax(ConnectContext ctx, Object[] args) throws Exception {
        if (args.length < 1) {
            throw new IllegalArgumentException("CALL syntax requires table_name as first parameter");
        }
        
        // 解析表名参数
        String tableNameStr = (String) args[0];
        List<String> parsedTableName = parseTableName(tableNameStr);
        
        // 获取其他参数 (跳过第一个table_name参数)
        Object[] procedureArgs = new Object[args.length - 1];
        System.arraycopy(args, 1, procedureArgs, 0, args.length - 1);
        
        LOG.info("CALL expire_snapshots for table: {}", tableNameStr);
        executeExpireSnapshots(ctx, parsedTableName, procedureArgs);
    }

    /**
     * 通过ALTER TABLE EXECUTE语法执行
     * ALTER TABLE iceberg_catalog.db.table EXECUTE expire_snapshots('2024-01-01', 5)
     */
    private void executeViaAlterTableSyntax(ConnectContext ctx, List<String> tableName, Object[] args) throws Exception {
        LOG.info("ALTER TABLE EXECUTE expire_snapshots for table: {}", String.join(".", tableName));
        executeExpireSnapshots(ctx, tableName, args);
    }

    /**
     * 核心执行逻辑 - 两种语法共享
     */
    private void executeExpireSnapshots(ConnectContext ctx, List<String> tableName, Object[] args) throws Exception {
        String olderThan = args.length > 0 ? (String) args[0] : null;
        Integer retainLast = args.length > 1 ? (Integer) args[1] : 1;
        Integer maxConcurrentDeletes = args.length > 2 ? (Integer) args[2] : 1;
        
        // TODO: 实际的expire snapshots执行逻辑
        LOG.info("Expiring snapshots for table {} with parameters: olderThan={}, retainLast={}, maxConcurrentDeletes={}", 
                tableName, olderThan, retainLast, maxConcurrentDeletes);
        
        // 模拟执行
        Thread.sleep(100);
        
        LOG.info("Successfully expired snapshots for table {}", String.join(".", tableName));
    }

    /**
     * 解析表名字符串 (支持catalog.db.table格式)
     */
    private List<String> parseTableName(String tableNameStr) throws IllegalArgumentException {
        if (tableNameStr == null || tableNameStr.trim().isEmpty()) {
            throw new IllegalArgumentException("Table name cannot be null or empty");
        }
        
        String[] parts = tableNameStr.split("\\.");
        if (parts.length < 1 || parts.length > 3) {
            throw new IllegalArgumentException("Invalid table name format: " + tableNameStr + 
                                             ". Expected format: [catalog.][database.]table");
        }
        
        // 返回标准化的三级名称
        if (parts.length == 1) {
            return Arrays.asList("", "", parts[0]); // 只有表名
        } else if (parts.length == 2) {
            return Arrays.asList("", parts[0], parts[1]); // database.table
        } else {
            return Arrays.asList(parts[0], parts[1], parts[2]); // catalog.database.table
        }
    }

    @Override
    public ProcedureCategory getCategory() {
        return ProcedureCategory.TABLE_MAINTENANCE;
    }

    @Override
    public boolean supportsCallSyntax() {
        return true;
    }

    @Override
    public boolean requiresSpecificTable() {
        return true;
    }
}
```

## 4. 使用示例

### 4.1 ALTER TABLE EXECUTE语法

```sql
-- Iceberg快照管理
ALTER TABLE iceberg_catalog.sales.orders EXECUTE expire_snapshots('2024-01-01 00:00:00', 5);
ALTER TABLE iceberg_catalog.sales.orders EXECUTE rollback_to_snapshot(123456789);
ALTER TABLE iceberg_catalog.sales.orders EXECUTE rewrite_data_files('binpack');

-- Paimon操作
ALTER TABLE paimon_catalog.warehouse.inventory EXECUTE compaction('partition1', 'major');
```

### 4.2 CALL语法 (新支持)

```sql
-- Iceberg快照管理 (需要显式指定表名)
CALL expire_snapshots('iceberg_catalog.sales.orders', '2024-01-01 00:00:00', 5);
CALL rollback_to_snapshot('iceberg_catalog.sales.orders', 123456789);
CALL rewrite_data_files('iceberg_catalog.sales.orders', 'binpack');

-- Paimon操作
CALL compaction('paimon_catalog.warehouse.inventory', 'partition1', 'major');

-- 全局操作类Procedure (不需要表名)
CALL global_cleanup(7); -- 清理7天前的临时文件
```

### 4.3 语法对比

| 语法类型 | 优点 | 缺点 | 适用场景 |
|---------|------|------|---------|
| `ALTER TABLE EXECUTE` | 表名隐式传递，语义清晰 | 语法相对复杂 | 表级维护操作 |
| `CALL procedure()` | 标准SQL语法，简洁 | 需要显式传递表名 | 通用Procedure调用 |

## 7. 技术优势

### 7.1 双语法兼容
- **ALTER TABLE EXECUTE**: 语义明确，适合表级操作
- **CALL**: 标准SQL语法，用户友好

### 7.2 统一底层实现
- 两种语法共享相同的`TableProcedure`框架
- 代码复用最大化，维护成本最低

### 7.3 灵活扩展性
- 支持表级和全局级Procedure
- 易于添加新的数据源和Procedure类型

### 7.4 向后兼容
- 不影响现有的CALL语法功能
- 不影响现有的PlSQL Procedure支持

## 8. 总结

本方案实现了Apache Doris对两种Procedure调用语法的完整支持：

✅ **ALTER TABLE EXECUTE语法** - 表级操作的自然语法  
✅ **CALL语法** - 标准SQL的通用语法  
✅ **统一框架** - 底层共享相同的TableProcedure实现  
✅ **完整功能** - 支持所有Iceberg和Paimon Procedure  
✅ **向后兼容** - 不影响现有功能  
✅ **灵活扩展** - 易于支持新的数据源和Procedure  

**预期实施时间**: 2-3周完成双语法的完整支持

这个方案为用户提供了最大的灵活性，既支持专业的表级操作语法，也支持标准的SQL调用语法，满足不同用户群体的需求。
